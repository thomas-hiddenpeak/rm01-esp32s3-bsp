# ESP32S3 配置管理优化总结

本次优化为ESP32S3控制台程序添加了完整的配置管理系统，实现了您所要求的所有功能。

## 🎯 主要功能

### 1. 风扇默认转速配置
- **默认开启速度**: 50% (可配置)
- **默认关闭速度**: 0% (可配置)
- **自动温控功能**: 支持温度阈值自动控制
- **配置保存**: 可保存为默认参数并在启动时加载

### 2. LED默认控制参数
- **默认亮度**: 50% (可配置)
- **板载LED默认颜色**: 蓝色 RGB(0,0,255) (可配置)
- **触摸LED默认颜色**: 绿色 RGB(0,255,0) (可配置)
- **LED效果控制**: 彩虹效果、渐变效果等
- **配置保存**: 支持颜色和亮度的默认值保存

### 3. 以太网控制配置
- **默认IP地址**: 10.10.99.97 (可配置)
- **默认网关**: 10.10.99.97 (可配置)
- **默认子网掩码**: 255.255.255.0 (可配置)
- **默认DNS服务器**: 8.8.8.8 (可配置)
- **自动启动**: 支持开机自动启动以太网

### 4. DHCP服务器控制配置
- **默认启用状态**: 启用 (可配置)
- **默认IP池范围**: 10.10.99.100-110 (可配置)
- **默认租约时间**: 24小时 (可配置)
- **最大客户端数**: 8个 (可配置)
- **自动启动**: 支持开机自动启动DHCP服务

### 5. 网关服务控制配置
- **默认启用状态**: 启用 (可配置)
- **NAT转发**: 默认启用 (可配置)
- **防火墙功能**: 默认关闭 (可配置)
- **自动启动**: 支持开机自动启动网关服务

## 🔧 控制台命令

### 基础配置管理命令
```bash
save          # 保存当前配置到NVS
load          # 从NVS加载配置
clear         # 清除NVS中的配置
```

### 高级配置管理命令
```bash
# 显示完整配置
config show

# 重置为工厂默认配置
config reset

# 应用配置到所有子系统
config apply

# 设置风扇默认参数
config set fan <开启速度> <关闭速度> [自动控制]
# 示例: config set fan 70 0 true

# 设置LED默认参数
config set led <亮度> <板载R> <板载G> <板载B> <触摸R> <触摸G> <触摸B>
# 示例: config set led 80 0 0 255 0 255 0

# 设置以太网配置
config set eth <IP> <网关> <掩码> <DNS>
# 示例: config set eth 10.10.99.98 10.10.99.1 255.255.255.0 8.8.8.8

# 设置DHCP参数
config set dhcp <启用> <起始IP> <结束IP> <租约小时>
# 示例: config set dhcp true 10.10.99.100 10.10.99.110 24

# 设置网关参数
config set gateway <启用> <NAT> <防火墙>
# 示例: config set gateway true true false
```

### 默认参数管理命令
```bash
# 显示所有默认参数
defaults show

# 应用所有默认参数
defaults apply

# 应用特定组件的默认参数
defaults fan      # 应用风扇默认参数
defaults led      # 应用LED默认参数
defaults eth      # 应用以太网默认参数
defaults dhcp     # 应用DHCP默认参数
defaults gateway  # 应用网关默认参数
```

## 📁 新增组件

### Config Manager组件
- **位置**: `components/config_manager/`
- **功能**: 统一配置管理，支持NVS存储和数据验证
- **特性**: 
  - 配置完整性检查 (CRC32校验)
  - 版本管理和兼容性检查
  - 事件回调机制
  - 自动应用配置到子系统

### 配置结构
```c
// 完整的系统配置结构
typedef struct {
    fan_config_t fan;           // 风扇配置
    led_config_t led;           // LED配置
    ethernet_config_t ethernet; // 以太网配置
    dhcp_config_t dhcp;         // DHCP服务器配置
    gateway_config_t gateway;   // 网关服务配置
    system_config_t system;     // 系统配置
    uint32_t config_version;    // 配置版本
    uint32_t checksum;          // 校验和
} complete_config_t;
```

## 🚀 启动流程

系统启动时会自动：

1. **初始化配置管理器**
2. **尝试从NVS加载保存的配置**
   - 如果找到有效配置，加载并验证
   - 如果没有找到或配置损坏，使用默认配置
3. **应用配置到所有子系统**
   - 风扇控制系统
   - LED控制系统
   - 以太网接口
   - DHCP服务器
   - 网关服务

## 💾 数据存储

- **存储方式**: NVS (Non-Volatile Storage)
- **命名空间**: `device_config`
- **数据验证**: CRC32校验确保数据完整性
- **版本管理**: 支持配置格式升级和兼容性检查

## 🔐 安全特性

- **数据完整性**: CRC32校验和验证
- **参数验证**: 所有输入参数都有范围检查
- **错误处理**: 完善的错误处理和回退机制
- **默认值**: 安全的出厂默认配置

## 📊 使用示例

```bash
# 查看当前配置
ESP32S3> config show

# 设置风扇默认为开启70%，关闭0%
ESP32S3> config set fan 70 0

# 设置LED默认亮度80%，板载红色，触摸蓝色
ESP32S3> config set led 80 255 0 0 0 0 255

# 保存配置
ESP32S3> save

# 重启后配置会自动加载
ESP32S3> reboot
```
